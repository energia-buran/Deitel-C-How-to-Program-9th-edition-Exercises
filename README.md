# Deitel-C-How-to-Program-9th-edition-Exercises

My solutions to Exercises in the end of each chapter (not Self-Review Exercises) from the book "C How to Program, 9th edition", by Paul and Harvey Deitel. 

## Prerequisites

All solutions were compiled and tested in this environment.

* **Compiler:** Apple clang version 17.0.0 (clang-1700.6.3.2), Target: arm64-apple-darwin24.6.0
* **Operating System:** macOS 15.8.3, Apple M4 Pro

## Build the project

Clang compile options:

clang -std=c17 -g -O0 -Wall -Wextra
